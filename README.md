# Pokédex

Una aplicación web en React que usa la PokeAPI para mostrar una lista de Pokémon y buscar detalles de un Pokémon específico.

## Cómo usar
1. Clona este repositorio.
2. Instala las dependencias con `npm install`.
3. Inicia la aplicación con `npm start`.
4. Navega a `http://localhost:3000` para ver la Pokédex.

## Funcionalidades
- Lista de los primeros 150 Pokémon.
- Búsqueda de Pokémon por nombre con detalles (altura, peso, imagen).
- Interfaz responsiva con navegación.

## Requisitos
- Node.js
- npm

## Dependencias
- react
- react-dom
- react-router-dom
- react-scripts
